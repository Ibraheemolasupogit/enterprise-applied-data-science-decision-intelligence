## Numerical review

A20's Gaussian Hessian draws live on an unbounded log scale. The original conditional predictor exponentiated the parameters and subtracted two unconditional log survivals. Either parameter exponentiation or intermediate products can overflow, and subtraction can lose the ratio even when both log survivals are representable. The correction is restricted to finite E1/E2 draws outside the existing fit box. E1 accumulates the logarithms of the beta-product factors. E2 evaluates the conditional cumulative hazard for `x = bvj/(1+bva)` as `log1p(x)/v` in the log domain, with cancellation removed in the small-`x` limit. The fit likelihood, scores, covariance and parameter sampling code are unchanged.

The in-box predictor retains the original arithmetic. An independent Decimal reference and extreme finite inputs cover both tail formulas, including zero age and the E2 geometric limit. A bounded synthetic contractual R2 fixture reproduces the old exception, preserves ordinary coverage rows exactly and preserves both RNG stream states after the corrected overflow case. The new tail arithmetic can change previously finite probabilities, simulated values and coverage counts through rounding and avoidance of cancellation. Bitwise equivalence for those inputs and equivalence to a completed A20 output cannot be established.

A20's sampled peak of **3,912,499,200 bytes** left **87,500,800 bytes** below the ceiling before the run stopped at **3,743.24 seconds**. That partial run and the bounded fixture do not establish remaining runtime or full-workload memory headroom. The fix covers finite contractual draws. Non-finite draws and independent numerical failures in other models remain outside its scope.
