## 1. Tier B advantage and oracle calibration (`signals_contractual`)

`D` is the paired difference in realised squared error between the exact Tier A and Tier B oracles; in population expectation `D = E[(mu_B - mu_A)^2] >= 0` (amendment 1). The gate column is the z-statistic of `mean(D_i - (mu_B - mu_A)_i^2)`, whose expectation is 0; a single seed's sign of `D` is reported, not required. `relative Tier B advantage` = `E[(mu_B - mu_A)^2] / MSE_B` is the excess error of the Tier A oracle relative to the Tier B noise floor, directly comparable with the relative MDE (`4k^2/N`, alpha = Holm's strictest step). Calibration slopes regress realised value on each oracle (1 for a calibrated predictor).
