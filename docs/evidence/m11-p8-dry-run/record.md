- R1, R2 and R3 use the same coverage-block draws (seed COVERAGE_SEED_START + r): R2 the first MIN_COVERAGE_REPLICATIONS of R1's draws, R3 the first R3_REPLICATIONS at each scale (the scale changes only acquisitions_per_month). Draws are independent within each study; the studies are dependent on one another and are never pooled or combined. Within a draw every scenario's generator receives the same integer seed; analyses of different scenarios are never combined within a draw.
- No refit-bootstrap validation of E3 is performed (owner decision, P8 preflight): E3's parameter intervals rest on the CR1 sandwich, conditional on the chosen penalty, and are reported as not validated by a refit bootstrap.
- P8 repeated-sampling E4 parameter and predictive draws may use the accelerated computation: one Gauss-Jacobi rule for Beta(a, b) per parameter draw, reweighted exactly by (1 - p)^x B(a, b) / B(a, b + x), the window's expected purchases from its first and last edges (the monthly terms telescope), and all parameter draws at once; only for customers with x <= E4_ACCELERATED_MAX_X repeat purchases (the range validated at the P8 preflight: relative difference <= 2e-11 from the per-count rule); every other customer uses the original per-count Gauss-Jacobi rule unless the accuracy is independently established and recorded. Point predictions and P7's e4_simulate (and so P7's record) are unchanged.
- Coverage: mean per-draw coverage with its 95% t interval across independent draws, classified below / consistent with / above nominal; pooled customer coverage is descriptive.
