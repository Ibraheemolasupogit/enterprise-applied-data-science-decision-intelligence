### Pooled cutoffs and customer clustering (amendment 2)

Kish design effect with the actual cluster sizes, `n_eff = n / (1 + rho (sum m_g^2 / n - 1))`; `rho` is the within-customer correlation of the paired loss difference across cutoffs (unknown; positive here because the 12-month windows of cutoffs 24 and 30 overlap by 6 months), so `rho = 1` is the conservative planning value. Clustering *raises* the detectable difference relative to treating rows as independent (`rho = 0`); the pooled value is still below the single-cutoff value because pooling adds distinct customers and partly independent second rows.

### General case: SE of a paired MSE difference, first cutoff

`SE = 2 tau sigma / sqrt(N)` where `tau` is the RMS difference between two models' predictions; the difference is detectable when it exceeds `k SE`.
