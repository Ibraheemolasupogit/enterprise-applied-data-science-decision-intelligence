# Milestone 11 — protocol amendments before main-seed evaluation

The M11 protocol (`src/decision_intelligence/customer_value/predictive_protocol.py`) was
committed at P0 (`82e3ebd`). Every later change is listed here and in the protocol's own
`PROTOCOL_AMENDMENTS`. **A1–A13 were made before any main-seed computation; A14 was made after
the first final attempt had computed the main-seed analysis but before any main-seed result was
inspected**. The protocol records this explicitly: A14 has `before_main_seed=False` and
`before_outcome_inspection=True` and is the only amendment in
`AMENDMENTS_AFTER_MAIN_SEED_COMPUTATION`; `validate_protocol` requires every other amendment to
precede any main-seed computation and every amendment to precede any outcome inspection. Until
A13 the main and fresh seeds could not be authorised (`authorise_seed` refuses them while
`PENDING_BEFORE_MAIN` is non-empty); A13 closed the last item. The first final attempt computed
the main-seed analysis (never opened) and ran the coverage and refit blocks, then failed before
storing any repeated-sampling result; the fresh seed has not been used.

   `E3_TUNING_LOSS` by amendment, or accept it as a documented implementation convention.
   **Resolved by A10** (`E3_NO_OK_FIT_RULE`); no code changed.

   fixed by amendment before P7 implements it. **Resolved by A10** (`B2_DEFINITION`; also
